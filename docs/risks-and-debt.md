## Validation limits

Package checks cannot prove automatic skill selection, universal agent compliance, a real production
migration or native behavior on an operating system where the particular check was not run. Isolated
behavioral exercises provide bounded evidence only. Historical CI results remain tied to their stated
revision; new results must be recorded separately.
