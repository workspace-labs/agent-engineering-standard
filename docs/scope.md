# Scope

## Product

Ship one portable Agent Skill that guides software work with clear responsibilities, proportional
structure, tests, documentation and owner-controlled major decisions. The product source is
[the installed package](../skills/software-engineering-build-standard/SKILL.md), not an executable app.

## Included

- A concise entrypoint and focused reference guides, with stable rule citations.
- Staged project-tree examples that explain when responsibilities are earned.
- Optional Codex display metadata, offline integrity checks and realistic isolated agent exercises.
- Install instructions and dated evidence that separates package checks from agent behavior.

## Excluded

No runtime application, dependency installation, automatic project migration, mandatory technology
choice or speculative empty scaffold. Examples never override accepted project/framework/engine layouts.
No secrets, user records or machine-specific paths belong in the published package or evidence.

## Quality

Every bundled reference must be reachable and every local link must resolve within its declared
boundary. Tests must reject malformed packages without running installed instructions. Behavioral
claims require observed artifacts and command results; static checks alone are insufficient.
